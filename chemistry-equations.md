# Chemistry, Reduced to Sums & Differences

A compressed reference: chemistry categories as equations rather than
prose definitions. Each branch introduces its own "currency" (electrons,
protons, energy, moles) — that's called out where it shifts. Flagged notes
mark: genuine memorization tables (nothing above them derives the answer),
real exceptions, and small mechanism anecdotes worth keeping attached to
the equation.

---

## 1. Core Build

```
Proton + Neutron + Electron = Atom  (neutral, P = E)
```

### Charge family (electron transfer — proton count unchanged)
```
Atom − Electron = Cation   (net positive)
Atom + Electron = Anion    (net negative)
Cation, Anion = Ion        (either direction is an Ion)
```

### Isotopes (a comparison, not a sum)
```
Same Proton, Different Neutron = Isotopes (of each other)
```

### Bonding — atoms joining
```
Atom + Atom (same element) = Molecule                    e.g. O2, N2
Atom + Atom (different elements) = Molecule + Compound    e.g. H2O, CO2
```
> Compound is a *label*, not "Molecule + Molecule." Every compound is a
> molecule; not every molecule is a compound.

### Radical
```
Molecule − Electron = Radical   (unpaired electron; usually neutral, not "anionic")
```

### Metal / Non-metal — kept equational, not a fixed label
```
Full Outer Shell − Electron(s), small gap (1–3) = Non-metal
Full Outer Shell − Electron(s), large gap (4+, shell mostly empty) = Metal
Full Outer Shell ± 0 = Noble Gas
```
> Small gap → easier to gain the last few electrons → Anion-forming.
> Large gap → easier to shed the few it has → Cation-forming. Metal/
> non-metal falls out of *distance to a full shell*, same currency as
> the Ion line above — not a separate categorical fact.

## 2. Bonding Types (closes the loop on Atom + Atom above)

```
Atom + Atom (share Electrons) = Covalent Bond
Atom + Atom (transfer Electrons) = Ionic Bond
Atom + Atom (delocalize Electrons, metal + metal) = Metallic Bond
```
> "Atom + Atom = Molecule" was silent on mechanism. Three different
> electron-handling operations, same reactants-in.

### Covalent — polar vs non-polar
```
Shared Electrons (equal pull) = Non-polar Covalent Bond
Shared Electrons (unequal pull) = Polar Covalent Bond
Electronegativity Difference UP = Bond Polarity UP
Electronegativity Difference (very large) = Ionic, not Covalent
```
> Ionic and Covalent aren't two separate boxes — one continuous scale.
> Ionic bonding is covalent bonding taken to an extreme.

### Consequences (why each bond type behaves the way it does)
```
Cation + Anion (electrostatic, all directions) = Ionic Lattice
Ionic Lattice = High Melting Point, Brittle, Conducts only when molten/dissolved

Shared Electron Pair (localized, fixed) = Discrete Molecule
Discrete Molecule x many, weak forces between = Low Melting Point, Doesn't conduct

Metal Atom − outer Electron(s) -> shared "sea" among Cations = Metallic Bond
Delocalized Electron Sea = Conducts (always), Malleable, Ductile
```
> Ionic lattice attraction pulls in every direction at once — shift one
> layer and same-charge ions repel violently -> brittle. Metallic sea has
> no fixed attachment direction — ions slide and resettle -> malleable.
> Same underlying idea (directionality), opposite mechanical result.

## 3. Intermolecular Forces (one level down from Bonding — whole molecules
attracting each other, not atoms inside one)

```
Molecule + Molecule (temporary electron imbalance, all molecules) = London Dispersion
Molecule + Molecule (permanent Dipole, polar molecules) = Dipole-Dipole
Molecule + Molecule (H bonded directly to N, O, or F) = Hydrogen Bond

Hydrogen Bond > Dipole-Dipole > London Dispersion
Intermolecular Force Strength UP = Boiling/Melting Point UP
```
> London Dispersion is present in EVERY molecule, including non-polar
> ones — not "the weak one that doesn't count." It's why even non-polar
> gases can be liquefied given enough size/surface area.

### Water — why it's the odd one out
```
Oxygen (2 lone pairs) + Hydrogen x2 = Bent Geometry
Bent Geometry + Highly Polar O-H bonds = Strong Net Dipole
Strong Net Dipole + H bonded to O = Extensive Hydrogen Bonding Network
```

### Ice floating — the one line that breaks the general pattern
```
Liquid Water (tumbling, packed tightly) = Higher Density
Ice (H-Bonds lock into open hexagonal lattice) = Lower Density
Lower Density Solid = Floats on its own Liquid
```
> Almost everywhere else: Solid > Liquid in density. Water trades
> "tightly packed" for "correctly bonded" — the hydrogen-bond geometry
> forces an open cage on freezing. A false-seeming exception that's
> actually derivable from the equation itself.

## 4. Ion & Redox

### Redox core (same currency as Section 1's Ion line, now tracking direction)
```
Substance + Electron = Reduced (charge down)
Substance − Electron = Oxidized (charge up)
Oxidation + Reduction = Redox Reaction   (always paired)
```

### Agents (named for what they do to the OTHER substance)
```
Substance (causes another to be Reduced, itself Oxidized) = Reducing Agent
Substance (causes another to be Oxidized, itself Reduced) = Oxidizing Agent
```
> Opposite naming convention from Acid/Base, which name the substance's
> own behavior. First pass, everyone gets this backwards.

### Oxidation state
```
Oxidation State (increases) = Oxidized
Oxidation State (decreases) = Reduced
Oxidation State (unchanged) = Not a redox step
```

### Electrochemical cell
```
Reducing Agent (loses e-) -> wire -> Oxidizing Agent (gains e-) = Electrochemical Cell
Electrode (Oxidation happens here) = Anode
Electrode (Reduction happens here) = Cathode
```

### Terminal polarity — flips between cell types, Anode/Cathode never does
```
Galvanic (spontaneous): Anode = Negative, Cathode = Positive
Electrolytic (forced):  Anode = Positive, Cathode = Negative

Anode = Oxidation, always
Cathode = Reduction, always
Anode/Cathode polarity = depends on Galvanic vs Electrolytic
```
> Charge is downstream and context-dependent; Anode/Cathode is defined
> by the reaction, not by charge. "Positive terminal" isn't a fixed
> identity of either one.

## 5. Acid, Base, Salt (proton currency, not electron)

```
Substance (donates Proton, H+) = Acid
Substance (accepts Proton, H+) = Base
Acid + Base = Salt + Water          (neutralization)
```

### Strength (ionization completeness) vs Concentration (amount dissolved)
```
Acid (fully ionizes) = Strong Acid      Acid (partially ionizes) = Weak Acid
Base (fully ionizes) = Strong Base      Base (partially ionizes) = Weak Base
```
> Strength != Concentration. A concentrated weak acid and a dilute
> strong acid are both real, both different. Easy to conflate.

```
Strong Acid + Strong Base = Salt (neutral, pH 7)
Strong Acid + Weak Base   = Salt (acidic, pH < 7)
Weak Acid + Strong Base   = Salt (basic, pH > 7)
Weak Acid + Weak Base     = Buffer Solution
```
> The Weak+Weak line is the memorable short form. Precisely: a buffer
> needs the acid and base to be a matched CONJUGATE pair coexisting at
> once — not any two unrelated weak substances thrown together, which
> would just neutralize normally.
```
Weak Acid + Conjugate Base (of that acid) = Buffer Solution
Weak Base + Conjugate Acid (of that base) = Buffer Solution
```

### pH
```
High H+ concentration = Low pH = Acidic
Low H+ concentration  = High pH = Basic
H+ concentration = OH- concentration = Neutral (pH 7)
```

### Salt hydrolysis (mechanism behind the three-salt-type table above)
```
Salt (Strong Acid + Weak Base) + Water -> excess H+  -> Acidic
Salt (Weak Acid + Strong Base) + Water -> excess OH- -> Basic
```

## 6. Thermodynamics / Equilibrium (currency: energy + concentration)

```
Reaction (releases heat) = Exothermic       ; ΔH negative
Reaction (absorbs heat)  = Endothermic      ; ΔH positive
ΔH = Enthalpy(Products) − Enthalpy(Reactants)

ΔS = Entropy(Products) − Entropy(Reactants)
ΔS positive = disorder increases (e.g. solid -> gas)
```

### Gibbs Free Energy — the line that actually decides spontaneity
```
ΔG = ΔH − (Temperature x ΔS)
ΔG negative = Spontaneous
ΔG positive = Non-spontaneous
ΔG = 0 = Equilibrium
```
> A reaction can be endothermic AND spontaneous if ΔS is positive enough
> and Temperature is high enough to outweigh ΔH. "Exothermic = spontaneous"
> is a shortcut this equation forbids. Temperature is a lever, not a
> side note — heating alone can flip non-spontaneous to spontaneous.

### Equilibrium constant — where it settles, not whether it moves
```
K = [Products] / [Reactants] at equilibrium
K large (>1) = Products favored     K small (<1) = Reactants favored
```
> K tells you where a reaction ends up; ΔG tells you whether it gets
> there on its own. Related, not the same question. A favorable K with
> a very slow rate is a Kinetics problem, different branch entirely.

### Le Chatelier — one sentence explains all five lines
```
Equilibrium + Added Reactant       = Shift toward Products
Equilibrium + Added Product        = Shift toward Reactants
Equilibrium + Increased Pressure   = Shift toward fewer gas molecules
Equilibrium + Increased Temperature= Shift toward endothermic direction
Equilibrium + Removed Substance    = Shift toward replacing it
```
> Underlying idea: the system always shifts to partially undo whatever
> stress was applied. All five lines are derivable from that one rule.

### Catalysts — the most common wrong intuition in this branch
```
Catalyst + Reaction = Faster Rate (both directions, equally)
Catalyst + Equilibrium Position = No change
Catalyst + K = No change
```
> Gets you to equilibrium faster; does NOT move where it sits. A
> kinetics lever wearing a thermodynamics disguise.

## 7. Kinetics

```
Rate = Δ[Concentration] / Δ Time
Rate = k [A]^m [B]^n        (k = Rate Constant; m,n = Order, found experimentally)
m + n = Overall Order
```
```
Order 0 = Rate unaffected by concentration
Order 1 = Rate proportional to concentration
Order 2 = Rate proportional to concentration^2
```
```
Reactants + Activation Energy (Ea) -> Transition State -> Products
Ea high = Slow    Ea low = Fast
```
```
Catalyst + Reaction = New Pathway, Lower Ea
Lower Ea = Faster Rate (forward and reverse, equally)
```
```
Temperature UP = Kinetic Energy UP = More Successful Collisions = Rate UP
```
```
k = A x e^(−Ea / RT)          (Arrhenius Equation)
Ea UP or T DOWN = k DOWN = Rate DOWN
Ea DOWN or T UP = k UP = Rate UP
```
```
Successful Collision = Correct Orientation + Sufficient Energy (>= Ea)
Concentration UP or Surface Area UP = Collision Frequency UP = Rate UP
```

## 8. Carbohydrates (Glucose-type)

```
Carbon + Hydrogen + Oxygen (ratio ~1:2:1) = Carbohydrate
```
```
Simplest Sugar (single unit, e.g. Glucose, Fructose) = Monosaccharide
Monosaccharide + Monosaccharide − Water = Disaccharide
Disaccharide + Disaccharide (repeated) − Water (repeated) = Polysaccharide
```
> `− Water` is the actual reaction — a condensation/dehydration bond.
> Reverse (breaking it back apart) puts the water back in: hydrolysis.
> Same mechanism reused across this whole file — see Esters, Soap.

```
Glucose (open chain) <-> Glucose (ring form, cyclic)     — ring form most abundant in solution
```

### Named disaccharides — memorization, no equation derives which pair gets which name
```
Glucose + Fructose = Sucrose (table sugar)
Glucose + Galactose = Lactose (milk sugar)
Glucose + Glucose   = Maltose (malt sugar)
```

### Named polysaccharides — same honesty
```
Glucose x many (energy storage, plants)  = Starch
Glucose x many (energy storage, animals) = Glycogen
Glucose x many (structure, plants)       = Cellulose
```
> All three are the exact same monomer (Glucose). The only difference
> between digestible energy store and indigestible fiber is the
> geometry of the link — same building block, different bond angle,
> completely different biological role.

## 9. Reactions, Tests & Preparations

### Soap (confirms: soap IS a salt)
```
Fat/Oil (Ester of Fatty Acid + Glycerol) + Strong Base (NaOH/KOH) = Soap (Salt) + Glycerol
```
> Saponification. Fits the ABS branch exactly: Fatty Acid (weak acid) +
> NaOH (strong base) = Salt.
```
Soap Molecule = non-polar Hydrocarbon "tail" + polar/ionic "head"
Tail (grabs Oil) + Head (grabs Water) = Emulsification
```
> One molecule, both ends doing different jobs simultaneously — same
> "like dissolves like" rule from the Bonding branch.

### Qualitative gas tests
```
Gas + Glowing Splint -> Relights          = Oxygen
Gas + Lit Splint -> Pop                   = Hydrogen
Gas + Limewater -> Milky/Cloudy           = Carbon Dioxide
Gas + Damp Red Litmus -> Blue             = Ammonia
Gas + Damp Blue Litmus -> Red             = Acidic Gas (CO2, SO2, HCl)
Gas + Moist Litmus -> Bleaches White      = Chlorine
```

### Cation tests (NaOH, dropwise)
```
+ NaOH -> White ppt, insoluble in excess = Al3+, Ca2+, Mg2+, Zn2+ (ambiguous, needs 2nd test)
+ NaOH -> White ppt, DISSOLVES in excess = Al3+ or Zn2+ specifically
+ NaOH -> Blue ppt            = Cu2+
+ NaOH -> Green ppt           = Fe2+
+ NaOH -> Reddish-Brown ppt   = Fe3+
```
> Al3+/Zn2+ dissolving in excess = **amphoteric** — acts as either acid
> or base depending on partner. The one spot here that doesn't sit
> cleanly on one side of the Acid/Base branch; genuinely both.

### Anion tests
```
+ dilute HCl -> Effervescence (CO2, turns limewater milky) = Carbonate
+ dilute HNO3 + AgNO3 -> White ppt   = Chloride
+ dilute HNO3 + AgNO3 -> Cream ppt   = Bromide
+ dilute HNO3 + AgNO3 -> Yellow ppt  = Iodide
+ dilute HCl + BaCl2 -> White ppt (insoluble in acid) = Sulfate
```
> The AgNO3 tests are literally the same reaction as the general
> Precipitation/Double Decomposition prep below, just run as a test.

### Flame tests (memorization — no equation derives the colors)
```
K+  -> Lilac/Purple
Na+ -> Golden Yellow
Ca2+-> Brick Red
Ba2+-> Green   (Cu2+ also green, distinct blue-green)
Li+ -> Crimson Red
```
> Mechanism underneath: electrons excited by flame heat fall back down,
> releasing light at a wavelength specific to that element's structure —
> same idea as electron transitions elsewhere, just visible.

### Industrial preparations
```
Zinc + dilute Sulfuric Acid = Zinc Sulfate + Hydrogen        (standard lab H2 prep)
NaCl (molten) + Electrolysis = Sodium + Chlorine              (Downs Process)
NaCl (concentrated aqueous) + Electrolysis = NaOH + Cl2 + H2  (Chlor-alkali Process)
Nitrogen + Hydrogen (high P/T, catalyst) = Ammonia            (Haber Process)
Ammonia + Oxygen (catalyst) = Nitric Acid (multi-step)        (Ostwald Process)
Sulfur + O2 -> SO2 (catalyst) -> SO3 + Water = Sulfuric Acid  (Contact Process)
Limestone (CaCO3) + Heat = Quicklime (CaO) + CO2              (Thermal Decomposition)
Quicklime (CaO) + Water = Slaked Lime (Ca(OH)2)               (exothermic)
```

### Haber Process — Le Chatelier applied on purpose (payoff of Section 6)
```
High Pressure  = fewer gas moles (Ammonia side) -> Yield UP
Lower Temp     = Yield UP (exothermic), but Rate DOWN (Kinetics)
Compromise Temp (~450C) = balances Yield vs Rate
```
> The entire reason industrial chemistry is hard: Thermo says go cold,
> Kinetics says go hot. The real operating temperature is a deliberate
> trade-off between two branches fighting each other.

### Displacement
```
Metal (more reactive) + Salt Solution (less reactive Metal) = Salt Solution (more reactive) + Metal (displaced)
Zinc + Copper Sulfate = Zinc Sulfate + Copper
Halogen (more reactive) + Halide Salt (less reactive) = Halide Salt (more reactive) + Halogen (displaced)
Chlorine + Potassium Bromide = Potassium Chloride + Bromine
```
```
Reactivity Series (memorization — not derivable):
K > Na > Ca > Mg > Al > Zn > Fe > Pb > (H) > Cu > Ag > Au
```
> Once memorized, every displacement reaction above becomes predictable
> from it — the one piece of raw data the rest of this section runs on.

### Esters
```
Carboxylic Acid + Alcohol (acid catalyst, heat) = Ester + Water     (same − Water move again)
Ester + Water (acid catalyst) = Carboxylic Acid + Alcohol            (Hydrolysis)
Ester + NaOH (base catalyst) = Salt of Acid + Alcohol                (Saponification — same bond, base breaks it)
```

### More gas preparations
```
Copper + dilute Nitric Acid = Copper Nitrate + Nitric Oxide + Water        (dilute -> NO)
Copper + concentrated Nitric Acid = Copper Nitrate + Nitrogen Dioxide + Water (conc -> NO2)
```
> Same two reactants, different gas, purely from concentration. Nitric
> acid is unusual — most acid+metal reactions just reliably give H2.
```
NaCl + MnO2 + Concentrated H2SO4 (heat) = Chlorine
MnO2 + Concentrated HCl (heat) = MnCl2 + Chlorine + Water
Ammonium Chloride + Sodium Nitrite (heat, aqueous) = Nitrogen + NaCl + Water
Sulfite Salt + dilute Acid = Salt + Sulfur Dioxide + Water
```

### Polymerization — two genuinely different mechanisms
```
Monomer (has C=C) x n -> Polymer                    (Addition — NO by-product)
Monomer A (2 groups) + Monomer B (2 groups) x n = Polymer + small molecule x n  (Condensation — by-product every time)
```
> Addition polymerization is the one exception in the whole "joining
> reactions" family that evicts nothing — everything else (esters,
> soap, sugars) consistently loses a small molecule.
```
Diacid + Diamine (repeated) − Water (repeated) = Polyamide (Nylon)
Diacid + Diol (repeated) − Water (repeated) = Polyester (PET)
```

### Fermentation
```
Glucose (Yeast, anaerobic) = Ethanol + Carbon Dioxide
Ethanol + Oxygen (bacterial, aerobic) = Ethanoic Acid (Vinegar) + Water
```
> Second line is oxidation (Redox branch) — why wine left open turns
> sour: airborne bacteria oxidizing the alcohol, not vague "going bad."

### Combustion
```
Hydrocarbon + O2 (excess)        = CO2 + Water   (Complete, exothermic)
Hydrocarbon + O2 (limited)       = CO + Water     (Incomplete)
Hydrocarbon + O2 (very limited)  = C (soot) + Water (Incomplete, worse)
```
> CO is colorless, odorless, binds haemoglobin far more strongly than
> O2 — the actual mechanism of CO poisoning. Not a minor efficiency
> difference; the difference between a safe appliance and a lethal one.

### Corrosion & prevention
```
Iron + Oxygen + Water = Hydrated Iron(III) Oxide (Rust)
```
> Both Oxygen AND Water required — either alone isn't enough. A Redox
> reaction: Iron oxidized, Oxygen reduced.
```
Iron + Zinc coating (more reactive) = protected (Sacrificial Protection — Zinc oxidizes instead)
Iron + Paint/Grease/Oil = protected (physical barrier, no redox)
Iron + Chromium (alloyed) = Stainless Steel (self-repairing Cr-oxide layer)
```
> Stainless steel isn't sacrificial — the layer reseals itself on scratch,
> continuous self-protection rather than a consumed coating.

### Aldehydes vs Ketones
```
Chain + Carbonyl (C=O) at END   = Aldehyde
Chain + Carbonyl (C=O) MID-chain = Ketone

Aldehyde + Tollens' Reagent (heat) = Silver Mirror + Carboxylic Acid ; Ketone = No reaction
Aldehyde + Fehling's Solution (heat) = Brick-Red ppt (Cu2O) + Carboxylic Acid ; Ketone = No reaction
```
> Both tests are Redox: aldehyde is readily oxidized, forcing the metal
> ion (Ag+ or Cu2+) to be reduced. Ketone's carbonyl has no attached H
> the way an aldehyde's does — structurally can't be oxidized the same way.

### Thermite
```
Aluminium + Iron(III) Oxide (ignition) = Aluminium Oxide + Iron (molten) + heat
```
> Same Reactivity Series logic as sacrificial protection, run in reverse
> on purpose: Al more reactive than Fe, rips oxygen away violently.

### Ammonium salts / HCl / insoluble salts / water of crystallization
```
Ammonium Salt + Strong Base (heat) = Salt + Ammonia + Water
NaCl (solid) + Concentrated H2SO4 (heat) = NaHSO4 + Hydrogen Chloride (gas)
HCl (gas) + Water = Hydrochloric Acid

Soluble Salt A + Soluble Salt B = Insoluble Salt (ppt) + Soluble Salt C   (Double Decomposition)
Silver Nitrate + Sodium Chloride = Silver Chloride (ppt) + Sodium Nitrate

Anhydrous Salt + Water = Hydrated Salt (Water of Crystallization)
Hydrated Salt + Heat = Anhydrous Salt + Water (driven off)
CuSO4 (Anhydrous, White) + Water = CuSO4.5H2O (Hydrated, Blue)
```
> White-to-blue CuSO4 is a standard test for the PRESENCE of water in an
> unknown liquid — same spirit as litmus/limewater tests.

## 10. Distinguishing Pairs (near-synonyms that get conflated)

### Nitrogen cycle — three that sound alike, aren't
```
Fixation:        N2 (gas)  -> usable Nitrogen compound   (bacteria / lightning / Haber)
Nitrification:   Ammonia   -> Nitrate                     (oxidation, usable -> more usable)
Denitrification: Nitrate   -> N2 (gas)                    (reverses fixation entirely)
```
> Fixation and Denitrification are direct opposites (gas <-> compound).
> Nitrification sits entirely on the "compound" side. Waterlogged soil
> loses fertility because anaerobic bacteria denitrify usable nitrate
> straight back into useless atmospheric N2.

### Oxidation vs Combustion vs Respiration
```
Oxidation   = any Electron loss (broadest term)
Combustion  = rapid Oxidation + visible heat/light
Respiration = slow, enzyme-mediated Oxidation of Glucose for cellular energy
Glucose + Oxygen = Carbon Dioxide + Water + Energy    (same equation, both cases)
```
> Identical net equation whether burning sugar in a flame or respiring
> it in a cell. Only difference: rate and control — combustion releases
> it all at once as heat/light, respiration gradually as usable ATP.

### Hydrolysis vs Hydration vs Dehydration
```
Hydrolysis  = bond broken USING water (water consumed, splits molecule in two)
Hydration   = water ADDED, no bond broken (e.g. Ethene + Water = Ethanol)
Dehydration = water REMOVED (reverse of hydration; the condensation move seen in Esters/Sugars/Soap)
```
> Hydrolysis and Hydration both "add water" but aren't the same
> operation — hydrolysis breaks a molecule apart, hydration doesn't
> break anything at all.

## 11. Mole & Stoichiometry (currency: mole count — bridges mass, particles, gas volume)

### Core conversions
```
Moles = Mass / Molar Mass
Moles = Number of Particles / Avogadro's Number (6.02 x 10^23)
Moles = Volume of Gas (at STP) / 22.4 L     <- only holds AT STP
```
> The 22.4 L line is the one with a hidden condition — change T or P
> and it's wrong, unlike the other two which always hold.

```
Molar Mass = Sum of (Atomic Mass x number of each Atom) in the formula
Concentration (mol/L) = Moles of Solute / Volume of Solution (L)
```

### Balanced equations — the ratio engine
```
Balanced Equation Coefficients = Mole Ratio, directly
2H2 + O2 = 2H2O  ->  2 mol H2 : 1 mol O2 : 2 mol H2O
```
> Every "A + B = C" built in Section 9 only ever said WHAT reacts with
> WHAT — never HOW MUCH. The coefficients you balance for were secretly
> mole ratios the whole time.

```
Moles of A -> (x Mole Ratio) -> Moles of B -> (x Molar Mass of B) -> Mass of B
```
> The full mechanical procedure for any stoichiometry problem in one line.

### Limiting Reactant
```
Reactant (fully consumed first) = Limiting Reactant
Reactant (leftover, unreacted)  = Excess Reactant
Amount of Product = determined ONLY by the Limiting Reactant
```
> Having "more" by mass or volume means nothing — what matters is moles
> compared against the ratio the equation demands.

### Percentage Yield
```
Percentage Yield = (Actual Yield / Theoretical Yield) x 100
```
> Theoretical = what the mole ratio predicts on paper. Actual is always
> somewhat less in real life — incomplete reactions, side reactions,
> product lost in collection. None of Section 9's preparations give
> 100% for real.

### Graham's Law (Diffusion vs Effusion, made calculable)
```
Rate of Diffusion/Effusion is proportional to 1 / sqrt(Molar Mass)
Rate(A) / Rate(B) = sqrt(Molar Mass B / Molar Mass A)
```
> A gas four times lighter diffuses TWICE as fast, not four times —
> the relationship runs through a square root.

### Solubility, made numerical
```
Solubility = Max Mass of Solute dissolving in 100g Solvent at a given Temp
Solute Mass > Solubility = Saturated + Undissolved Excess
Solute Mass < Solubility = Unsaturated
Solute Mass = Solubility  = Saturated, no excess
```
> "Insoluble" is really just a solubility value near zero, not a
> fundamentally different kind of behavior from "soluble."
